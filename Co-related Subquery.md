Difference between subquery and co-related subquery



1\. In sub-query the execution starts with inner query

1\. In co-related sub-query the execution starts with outer query



2\. In sub-query only the outer query depends on the inner query

2\. In co-related subquery both inner query and outer query interdependent.



3\. In sub-query we should not use any concept of joins

3\. In co-related query we have to use the concept of joins



4.In sub-query the outer query executes only one time.

4\. In co-related sub query the outer query executes twice.
